# Flujos de UX

## Flujos Principales
1. **Ver horario**
   Dashboard -> Seleccionar instructor -> Ver matriz semanal
2. **Asignar horario**
   Dashboard -> Clic en espacio vacío -> Seleccionar instructor, programa, grupo -> Guardar
3. **Resolver conflicto**
   Intentar asignar un espacio ocupado -> El sistema muestra una alerta de error -> El usuario selecciona un espacio diferente
