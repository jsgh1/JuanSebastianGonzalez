# Especificación de UI

## Componentes
- **ScheduleGrid**: Matriz, filas=`TimeSlots`, columnas=`Classrooms`. Verde=Libre, Azul=Reservado.
- **InstructorList**: Vista de tabla con paginación simple o desplazamiento.
- **ConflictAlert**: Notificación roja tipo toast en la esquina superior derecha.

## Colores
- Primario: `#004080` (equivalente al azul SENA)
- Éxito: `#28a745`
- Error: `#dc3545`
- Fondo: `#f8f9fa`
